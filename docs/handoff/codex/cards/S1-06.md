只用node:test/assert，fetch spy返回合成fixture，不启动网络/server/浏览器；测试
fixture只需固定key和占位值，不复制另一份真实中英运行词典。

- Rust `embedded_assets_match_closed_routes_and_mime`：六路表驱动核MIME、bytes非空/
  UTF8和文件对应；G06另核include/closure/缺文件/路径及symlink拒绝。
- Node `catalog_validation_and_locale_lookup_are_closed`：32键唯一、空/缺键拒绝，
  en/zh正确选择、未知locale拒绝；formatUsd两locale正确处理既有cents，不修改输入。
- Node `requests_use_only_two_literal_endpoints_and_closed_actions`：首次GET/四POST
  路径/参数/body≤256准确；非法action在fetch前拒绝；redirect/cache/credentials固定。
- Node `request_failures_never_become_partial_state_or_retries`：11typed错误、非200、
  网络reject、坏JSON/metadata/catalog/必需字段均失败，spy证明无自动重试/第二POST；
  导入模块不发请求、不访问DOM/storage。UI隐藏旧快照的实际DOM表现留浏览器验收。

dom.iterable]、types=[]、strict=false、noUnusedLocals/noFallthroughCasesInSwitch=true，
