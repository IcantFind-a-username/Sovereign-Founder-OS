## 纯 unit 验收

先写 RED（新类型/方法未实现）再最小 GREEN。tests 内共享私有 fixture helper
通过 new/apply 到达四状态，不给生产域新增测试构造器；数据表遍历，不复制 setup。

- `closed_actions_cover_every_reachable_transition`：四状态×四动作共 16 组合，
  比较完整 session 预期，同时断言价格/阶段及其他 graph 字段没有意外变化。
- `correct_price_and_promotion_are_idempotent_and_commute`：各重复两次不变，
  两顺序得到同一 session；价格精确 250_000→350_000，Lead→Customer。
- `reporting_search_is_read_only_in_every_reachable_state`：每状态重复 search，
  逐次整个 session 等于快照；不声称搜索结果投影已实现。
- `reset_reconstructs_exact_fixture_from_every_reachable_state`：每状态 Reset
  等于 new，再 Reset 仍相同，核原 fixture 全字段；fresh session 不继承旧修改。

任意价格/ID/文本、第五动作、搜索写入和错误 Reset 的拒绝由已接受 G01 的恶意
fixture 与精确生产 token 门覆盖；不新增自由输入 parser。S1-01 不更新 expected；
