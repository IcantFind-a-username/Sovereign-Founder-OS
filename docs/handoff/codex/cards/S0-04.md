# S0-04 — 单 controller 独占与中断恢复

**Revision 1 · Spec Frozen · 执行角色：worker。**运行状态唯一见 [backlog](../../../backlog.md)。分派前必须由 controller 填入当前 base_commit、卡 blob 与唯一报告路径；未填不得施工。

## 目标与前置

确保同一仓库多个 worktree 不会同时控制相同施工 lane，恢复时保留 attempt、失败和预算。

S0-03 已验收。

## 精确写入集合

- scripts/codex-control/lock.mjs
- scripts/codex-control/lock.test.mjs

另允许 controller 指定的本卡单一 worker report 文件。队列、卡、protocol/contracts、角色规范、全局 gate 与其他卡文件禁止 worker 改动。实现校验工具的卡只获准修改上列对应工具与测试，不因此取得改变自己验收标准的权限。

## 接口与做法

实现 [contracts §5](../contracts.md) acquireLock / releaseLock / checkResume。复用 git.mjs 的 Git common-dir 解析和 test-support.mjs 临时仓库 fixture；若前置卡未提供必需接口，先由架构卡补齐，禁止临时复制。

1. 先测试两个 controller 对同一 Git common dir 竞争只有一方成功。
2. 仅用排他的目录创建获取锁；不完整 owner 数据一律视为占用/损坏。
3. 释放时核对 owner 三字段；恢复时检查原 worker 已停止、阻塞解除、base/candidate 与记录一致。
