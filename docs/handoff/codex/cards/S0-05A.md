# S0-05A — Controller 的单一 CLI 入口

**Revision 1 · Spec Frozen · 执行角色：worker。**实际状态见 [backlog](../../../backlog.md)。依赖 S0-02、S0-03、S0-04 全部验收。分派时冻结 base、卡 blob、输入规范 blob 和报告路径。

## 目标与写入集合

把已经实现的状态/Git/check/lock 接口暴露为确定的命令，后续 Luna 无需临时拼接脚本或猜调用方法。

仅可写：

- scripts/codex-control/cli.mjs
- scripts/codex-control/cli.test.mjs
- controller 指定的本卡唯一报告。

不修改前置工具、任务卡、protocol/contracts、模型规范、backlog 或全局 gate。

## 契约

严格实现 [contracts §7](../contracts.md) 的单一入口、operation/request 字段和 exit code。只导入已有接口，不重写状态/Git/校验逻辑。JSON.stringify 是唯一输出序列化方式；请求中的任何文本都不能拼成 shell。

verify 每次重新检查实际 candidate，不能读取一份旧 GitEvidence 就宣称源码仍一致。CLI 不启动模型、不提交 Git、不自动写 Accepted 事件。
