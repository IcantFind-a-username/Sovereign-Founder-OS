**Revision 2 · Spec Frozen · 执行角色：worker。**运行状态唯一见 [backlog](../../../backlog.md)。分派前必须由 controller 填入当前 base_commit、卡 blob 与唯一报告路径；未填不得施工。

## 目标与前置

实现冻结事件格式与状态转换，让第三次 Luna 尝试、缺失独立审阅、历史清零在交接前被拒绝。

S0-00 文档契约已验收。与 S0-01 无代码依赖，但默认串行。

## 接口与做法

实现 [contracts v2 §2–3](../contracts.md) 的 validateTask / validateEvents / Validation，以及导出的 checkRecordKeys / isNonNegativeInteger / isRepoRelativePath。同步、纯函数、无 IO、无第三方包；后三个接口供后续卡复用，不能藏为私有 helper。

1. 先写针对错误转换的测试和一个最小合法流程，观察预期 RED。
2. 实现字段和事件检查，失败返回稳定 error；不依赖当前时间或 shell。
3. 按完整契约历史重放 revise，逐段核对对应的 actor/base；同任务跨 revision/重启保留 attempt、失败与单次 fallback 上限。
4. 区分恢复 Retryable/NeedsArchitect 任务状态和复活已终结 attempt；跨任务父子准入由 controller/reviewer 核实，不虚构纯函数已经读取其他任务。
