## What this licenses

Governance permission to treat RFC 0005 as Accepted Target design and to
progress later programs only as each program's own gates allow. Program 1A
may continue as an internal Experimental engine.

## What this does not license

1. Starting Program 1B0 implementation before a follow-up amendment admits
   a released Rust binding for SQLCipher exactly 4.17.0 (or a superseding
   amendment after 4.19.0 applicability review).
2. Product enrollment, workspace migration, format selection, a product
   dependency edge to the engine, or any user-facing protection / backup /
   recovery claim.
3. `PendingV2` / `ActiveV2` / founder-data confidentiality.

**Explicit separation:** Accepting RFC 0005 ≠ implementing 1B0 ≠ shipping
product ActiveV2.
